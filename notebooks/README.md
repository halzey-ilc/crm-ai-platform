# Проверка на GPU в Kaggle

`kaggle_gpu_eval.ipynb` прогоняет синтетические примеры через **настоящие** типы задач AI Platform
(промпты, контракты выхода, проверки привязки) на Qwen3.5-4B Q4_K_M под llama.cpp с GPU.
Очередь и база данных не нужны: задачи выполняет `tools/evalrun`.

**Только синтетические данные.** Kaggle — внешний сервис: реальные клиенты, звонки и документы
компаний туда не загружаются.

## Шаги

1. На своей машине собрать пакет (нужен Docker):

   ```bash
   scripts/build_kaggle_bundle.sh
   ```

   Получится `dist/kaggle-eval-bundle.zip`: `evalrun` (Linux, без зависимостей), наборы из
   `evaluation/datasets/` и `MANIFEST.txt` с контрольными суммами. Исходный код репозитория
   в пакет не входит.
2. На kaggle.com: **Datasets → New Dataset**, загрузить zip, видимость **Private**.
3. **Code → New Notebook → File → Import Notebook** → `notebooks/kaggle_gpu_eval.ipynb`.
4. Справа в **Settings**: Accelerator **GPU T4 x2**, Internet **On** (нужно подтвердить телефон
   в профиле Kaggle). **Add Input** → датасет из шага 2.
5. **Run All**. Первый запуск — около 15–20 минут: сборка llama.cpp (тег `b11960`, как в
   локальном образе) и загрузка модели (3 ГБ, sha256 сверяется).
6. Скачать `report.json` из вкладки **Output** и положить в `evaluation/reports/`.

Бесплатно: около 30 часов GPU в неделю, одна сессия — до 12 часов.

## Что измеряется

| Колонка | Смысл |
|---|---|
| `succeeded` | ответ прошёл контракт и проверки привязки |
| `output_not_grounded` | модель написала то, чего нет во входе (числа, цитаты, ссылки); платформа ответ отбросила |
| `checks_failed` | ответ прошёл контракт, но не совпал с ожиданием набора: не тот инструмент агента (`tool:…`), лишние действия (`max_actions`), нет честного «недостаточно данных» (`insufficient_data`), неверный следующий шаг |
| `first_try_ok` | прошло с первой попытки (повторы — как в оркестраторе, только для временных ошибок) |
| `contains_found_mean` | доля ожидаемых слов в ответе — грубая подсказка, не оценка качества |
| `latency_median_s`, `latency_max_s` | время одного ответа |

Смысл ответов проверяет человек: блокнот печатает каждый ответ.

Необязательная ячейка с Whisper распознаёт **собственную** тестовую запись (не звонки клиентов).

## Локально

`evalrun` работает и без GPU:

```bash
go run ./tools/evalrun -provider mock evaluation/datasets/*.jsonl          # проверить наборы
go run ./tools/evalrun -llm http://127.0.0.1:8080 evaluation/datasets/*.jsonl  # локальный llama.cpp
```
