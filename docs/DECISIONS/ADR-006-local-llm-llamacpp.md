# ADR-006: Локальная LLM — Qwen3.5-4B на llama.cpp

- Статус: принято (согласовано владельцем, 2026-10-28)
- Дата: 2026-10-29

## Проблема

Mock-провайдер проверяет конвейер, но не анализирует текст. Нужна настоящая
модель, которая:
- работает без внешних API (данные не покидают инфраструктуру);
- имеет лицензию, допускающую коммерческое использование и дообучение;
- запускается на CPU разработчика (GPU нет).

## Решение

- **Модель:** Qwen3.5-4B, вариант для диалога (Apache-2.0). Файл — GGUF Q4_K_M от
  bartowski (сторонний автор, собран из официальных весов), 3 013 027 808 байт, sha256
  `13c16f426047e2de38cd075bdade4a7bcbc8c774384876f677740cda65f8a983`. Скачивается
  `scripts/get_model.sh` вне git, контрольная сумма сверяется с oid из API Hugging Face.
- **Runtime:** llama.cpp server (C++, MIT), официальный образ
  `ghcr.io/ggml-org/llama.cpp:server`, закреплён по digest (сборка 11960). Это и есть
  C++ inference runtime из целевой архитектуры; свой движок не пишется.
- **Провайдер** `internal/modelgw/llamacpp`:
  - ответ модели ограничивается JSON-схемой (grammar llama.cpp);
  - режим «thinking» выключен;
  - пункты, цитата которых не найдена в тексте, отбрасываются;
  - ссылки в сводке ограничены грамматикой ссылками из входа;
  - затем публичный контракт проверяет job type (схема и grounding).
- **Запуск:** `make up-llm` (overlay `deployments/local/compose.llm.yaml`). Модель не
  публикуется на хост; к ней обращается только orchestrator. Один слот, worker
  concurrency 1.

## Измерения на машине разработчика (i7-1065G7, 4 ядра / 8 потоков, 7,6 ГБ RAM, без GPU)

- **Память:** ~3,7 ГБ.
- **Скорость генерации:** ~1,6–2,2 токена/с; обработка промпта 3–7 токенов/с (4 потока).
  Ограничение по JSON-схеме почти не замедляет: 1,6 против 1,65–2,2 т/с.
- **Время:** резюме звонка ~2–4 минуты.
- **Помехи:** при одновременно работающих minikube и стеке CRM нагрузка доходила до 12–15 и
  скорость падала ниже 1 т/с.
- **Тайм-ауты:** задачи — 10 минут, аренда воркера — 15 минут.

## Последствия

- Работа асинхронная (CRM забирает результат), поэтому минуты на ответ допустимы для резюме
  и ежедневных сводок, но не для интерактивного ассистента.
- Для production нужен сервер с GPU или мощный многоядерный CPU. Код и контракты от этого
  не меняются, меняется только `AI_LLAMACPP_URL`.
- Модель можно заменить на любую GGUF той же формы: другой файл в `AI_MODEL_REPO` /
  `AI_MODEL_FILE`, новая метка `AI_LLAMACPP_MODEL`. Перед заменой обязателен прогон
  `evaluation/`.
- Качество на русском и кыргызском измеряется на синтетическом наборе, а не на реальных
  звонках ([MODEL_EVALUATION.md](../MODEL_EVALUATION.md)).
