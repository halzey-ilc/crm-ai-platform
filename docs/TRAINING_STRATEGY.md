# Стратегия обучения

Статусы — [STATUS_LEGEND.md](STATUS_LEGEND.md).

## 1. Три контура

| Контур | Назначение | Статус |
|---|---|---|
| Local Development Lab | Разработка на CPU без GPU и платных сервисов; синтетические данные; воспроизводимые конфиги | ✅ |
| Cloud Training | Изолированные training jobs по разрешению | 📐 не реализовано; **никаких облачных вычислений не запускалось** |
| Production Serving | Только проверенные модели; обучение в production не запускается | 📐 этап G |

## 2. Training Toolkit (`training/toolkit`)

Изолированный Python-проект (Python 3.13, uv, `uv.lock`). CRM API он не
вызывает, модели не развёртывает.

| Возможность | Реализация | Статус |
|---|---|---|
| Конфигурация эксперимента | TOML (`experiments/*.toml`), валидация до запуска | ✅ |
| Проверка входных данных | `dataset.quality_report`: колонки, пропуски, дубликаты id, timestamps с часовым поясом, метки 0/1, запрещённые колонки | ✅ |
| Версионирование датасетов | Содержательная адресация: sha256 канонического CSV, `version` = первые 16 hex-символов | ✅ |
| Разбиение | Временное (train → valid → test по `created_at`), проверка отсутствия пересечений id | ✅ |
| Достаточность данных | `min_rows` и `min_positives`; при нехватке обучение отклоняется | ✅ |
| Обучение | baseline (prior) + логистическая регрессия (scikit-learn) | ✅ |
| Метрики | ROC AUC, PR AUC, Brier, log loss, precision/recall/F1 при пороге 0.5, калибровка по 10 корзинам, качество по группам (source) | ✅ |
| Артефакты | `runs/<run_id>/`: `manifest.json`, `quality.json`, `metrics.json`, `model.pkl` (+sha256), `report.md` | ✅ |
| Статус в реестре | Всегда `candidate`, `approved_for_deployment: false` | ✅ |
| Нейросети (PyTorch) | Добавится с первой задачей, где они нужны (классификация звонков) | 📐 |
| Каталог датасетов / registry как сервис | | 📐 |

### Запуск

```bash
make toolkit-install
make toolkit-test
make toolkit-experiment   # 5000 синтетических лидов, секунды на CPU
```

Последний локальный запуск (2026-10-28): датасет `6f87683d10dbe41a`, test ROC AUC
логистической регрессии **0.720** против **0.500** у baseline. Это проверяет только
работу pipeline на синтетике с известной закономерностью, **а не качество на реальных лидах**.

## 3. Правила

- Обучение **не** запускается автоматически при появлении датасета.
- Модель **не** развёртывается автоматически после обучения.
- Реальные данные компании используются только по согласованию, с provenance-записью и
  только в пределах одной компании (см. [AI_DATA_GOVERNANCE.md](AI_DATA_GOVERNANCE.md)).
- `model.pkl` — формат эксперимента, а не формат serving. Чужие pickle не загружать.
  Формат для serving (ONNX и т. п.) выбирается на этапе G.
- Артефакты и датасеты не коммитятся (`.gitignore`).

## 4. Cloud Training (проект требований, 📐)

Обязательные свойства будущего механизма: бюджет и лимит времени на задачу; лимит
ресурсов; секреты только из secret manager; доступ только к согласованному датасету
(подписанная ссылка на объект); контрольные точки в объектное хранилище; отмена;
гарантированное удаление временных ресурсов; результат регистрируется как
`candidate` только после проверки контрольных сумм. Провайдер не выбран.
**Запуск возможен только после явного разрешения владельца бюджета.**
