# Обозначения статусов

Во всех документах проекта используются одни и те же отметки:

| Отметка | Значение |
|---|---|
| ✅ | Реализовано и проверено (есть автоматический тест или воспроизводимая проверка, которая проходила) |
| 🟡 | Реализовано, но не проверено (код есть, проверки нет или она не запускалась) |
| 🟠 | Частично реализовано |
| 📐 | Спроектировано, но не реализовано |
| ⛔ | Заблокировано зависимостью (указано, какой) |

Отметка ✅ ставится только по факту прохождения проверки. Если проверка
выполнялась только локально (а не в CI), это указывается явно.
